MAportkey
《哈利波特：魔法觉醒》的研究，包含游戏资源和辅助功能。
基于 Python 3.12 开发，核心文件：./bin/ocrtk.py

ocrtk.py使用介绍：
  半自动辅助阿瓦达闪现射击（运行后，手动放阿瓦达，按 F 自动闪到最佳位置。）
下好Python 3.12，再根据requiments.txt下载库，用python ocrtk.py运行即可。
**F	核心功能：自动闪现**

R	显示/隐藏屏幕上的绘制

F5	显示/隐藏信息板

[	降低识别灵敏度（漏检多时按这个）
]	提高识别灵敏度（误检多时按这个）

WASD	微调黄点位置
Ctrl+S	保存当前设置
Ctrl+P	截个图存到 set 文件夹
ESC	退出程序

原理
截图：用 mss 只截取角斗场那块区域，省资源。
检测：把截图喂给 YOLOv8n 模型，输出每个人的边框。
找脚底：取框底部中间作为脚底像素点，再加上你调的偏移量（FOOT_OFFSET_Y 和 WASD 微调）。
坐标变换：事先标定了屏幕上四个角和游戏里四个角的位置，算出一个“透视变换矩阵”。这样任意屏幕点都能换算成游戏里的世界坐标（范围 -118~118，-86~86）。
算闪现落点：已知自己（mb）和敌人（eb）的世界坐标，从自己位置朝敌人方向延伸，直到撞到角斗场边界，那个点就是最远闪现落点。
点回去：把那个落点再变回屏幕坐标，用 pyautogui 点一下，完成闪现。
整个流程就是“看→算→点”，延迟主要花在模型推理上。

关于 CPU 加速
best.pt 是 PyTorch 格式，在 CPU 上完全能跑，但速度看电脑。我开了抽帧（默认每 2 帧推理一次，中间复用结果）来保帧率。
如果想更快：
转成 ONNX 格式（代码里 YOLO(MODEL_PATH) 其实支持 .onnx，你转一下可能更快）
或用 Intel OpenVINO、TensorRT 等
有 NVIDIA 显卡的话自动走 CUDA，速度起飞。

已知问题
模型阈值只能开到 0.3 左右，再高就漏检。希望有人能帮忙优化数据集或换模型。

项目结构
bin/：主程序 ocrtk.py、模型 best.pt、依赖 requirements.txt

obj/：角斗场 3D 模型和贴图（研究用）

tool/：辅助脚本
